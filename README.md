# EduGen — An Agentic AI Learning System for Java / OOP

FYP-2 build. Four collaborating agents teach and assess object-oriented
programming at **concept** level, with lessons and quizzes generated by an LLM
and grounded in a retrieval index built from your own source material.

COMSATS University Islamabad, Lahore Campus · BS Software Engineering · FYP 2023–2027

---

## Quick start

```bash
cd edugen

python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt

cp .env.example .env          # then open .env and paste your GROQ_API_KEY

python scripts/build_corpus.py   # writes the 44 concept notes
python -m rag.ingest             # builds the vector index
python run.py                    # http://localhost:5000
```

Optional, adds three open-licence Java textbooks to the knowledge base:

```bash
python scripts/fetch_books.py     # then: python -m rag.ingest --rebuild
```

Verify the whole system without a browser:

```bash
python scripts/smoke_test.py        # 52 end-to-end checks
python scripts/test_adaptivity.py   # 11 adaptive-policy scenarios
```

## What the four agents do

| Agent | Input | Output | File |
|---|---|---|---|
| **Coordinator** | student id | routing decision + execution trace | `agents/coordinator_agent.py` |
| **Performance Analysis** | question attempts | mastery per concept, trends, root causes | `agents/performance_analysis_agent.py` |
| **Adaptive Content** | weakness report | next concept + difficulty + **retrieval brief** | `agents/adaptive_content_agent.py` |
| **Concept Clarifier** | retrieval brief | RAG-grounded lesson or quiz + citations | `agents/concept_clarifier_agent.py` |

The Concept Clarifier is the only agent permitted to call an external LLM.

```
Student ──► Coordinator ──► Performance Analysis ──► Adaptive Content ──► Concept Clarifier
                                                                               │
                                                                    RAG index ─┘──► LLM
```

Watch it run live at **/pipeline**.

## Configuration

Everything lives in `.env` (see `.env.example`).

| Variable | Purpose |
|---|---|
| `GROQ_API_KEY` | Required for lesson and quiz generation |
| `EDUGEN_LLM_MODEL` | Default `llama-3.3-70b-versatile` |
| `EDUGEN_SECRET_KEY` | Keeps logins alive across restarts |
| `EDUGEN_EMBEDDING_BACKEND` | `auto` \| `sentence-transformers` \| `ollama` \| `hashing` |
| `EDUGEN_SHOW_LOGS` | `0` hides the floating agent console for a clean demo |

## Adding material to the knowledge base

Drop any `.pdf`, `.txt` or `.md` into `rag/corpus/books/` and run:

```bash
python -m rag.ingest --rebuild
```

The pipeline chunks it on headings, tags every chunk against the 44 canonical
concepts, embeds it and rebuilds the index. No code changes needed.
